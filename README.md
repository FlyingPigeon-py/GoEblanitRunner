# Давай ебланить

Браузерный раннер по мему «давай ебланить / пожалуйста давай ебланить». Белый кролик бежит по дивану, перепрыгивает будильники, срочные таски, созвоны и дедлайны, собирает морковки и копит минуты ебланства. Игровые часы идут с 09:00.

Играть: https://flyingpigeon-py.github.io/GoEblanitRunner/

Управление: пробел, ↑ или тап — прыжок, в воздухе ещё раз — двойной; ↓ — быстро вниз; P — пауза; M — звук; N — музыка.

## Как устроено

Чистый canvas 2D и WebAudio, без библиотек, ассетов и сборщика: `index.html` грузит модули из `js/` по порядку. Ядро (`js/core.js`) даёт события, слои отрисовки, модификаторы и физику; остальные модули подключаются к нему. Контракт между модулями — в [CONTRACT.md](CONTRACT.md), планы геймплея и графики — в [design/](design/).

## Локально

Любой статический сервер из корня репозитория:

```bash
python3 -m http.server 8000
```

Затем открыть http://localhost:8000.

## Проверки

```bash
node test/smoke.js
```

```bash
node test/fairness.js
```

`smoke.js` гоняет игру в фейковом DOM/canvas/WebAudio: автопилот, хаос-ввод, ресайзы, смена темы, бессмертный марафон и бот, который прыгает по точной физике. `fairness.js` проверяет, что каждое препятствие и паттерн честно проходимы.

## Деплой

На каждый пуш в `main` GitHub Actions прогоняет проверки и публикует `index.html`, `css/` и `js/` на GitHub Pages. `node build.js` собирает всё в один файл без обёртки документа — так игра публикуется как Claude Artifact.
