# П7 звук — заметки для соседей и интегратора

Всё в `js/audio.js`, без файлов и без своих data-записей. KTS-ветки только под `G.kts && G.kts.enabled`; с `?kts=off` звук прежний. Правок ядра не нужно. Другие модули `G.sfx` не зовут: всё реагирует на события ниже.

## На что звук реагирует

| Событие | Что звучит |
|---|---|
| `pickup` `cake` | хлопушки, дудка, свой мотив «С днём рождения» на музыкальной шкатулке; второй торт за забег — «странная» концовка |
| `pickup` `duck` | резиновый писк; легендарная — писк и «огонь» (вжух, треск, мощный аккорд) |
| `pickup` `frog` (и `toad`) | «ква-ква», музыка на 4 с мягче (фильтр и тише ударные) |
| `pickup` `echpochmak` / `chakchak` / `khryuchevo` / `cookie` | «ням-ням» (эчпочмак — ещё и золотой перезвон, чак-чак и печенье — хруст, хрючево — «хрю» перед «ням») |
| `pickup` `timesheet` | тик-так, штамп, «done» |
| `pickup` `plovClue` / `kazan` | шелест пакета и детективные три ноты / гонг казана |
| `pickup` `goodButton` | щелчок кнопки, затем 10 с музыка в мажоре: I–IV–V–I, хук «да-вай еб-ла-нить», бочка в пол, перезвон |
| `pickup` `cat` | «мяу» |
| `powerup` `vpn` | щелчок замка; `vpn` как пикап сам не звучит, чтобы не было дубля |
| `smash` связи (`call`, `ping`, `minute`, `voice`) при активном `vpn` после `hit` | глушение связи (рваный шум и «вьюу») вместо обычного «бдыщ» |
| препятствие `vacuum` въехало в кадр | короткий гул мотора (не петля), высота тона от `o.drift`; сбит — мотор глохнет; смерть — гул обрывается |
| препятствие `voice` въехало в кадр | «пик» записи и бубнёж голосового; лопнуло — «блуп»; смерть — голос «зажёвывает плёнку» |
| `kts:npc` `toxic` | `enter` — сервопривод и загрузка; `predict` — роботизированная речь (длина по `text`) и вредное «бип-бип»; `kind` — «сломанная» речь с заиканием и милый перезвон; `dive` — свист вниз; `blocked` — удар и выключение; `leave` — улёт |
| `kts:npc` `vivi`/`cat` с `phase: 'enter'`, `kts:event` `vivi` | Виви: «мяу» и победный аккорд (дубли в пределах 1,5 с гасятся) |
| `kts:event` `wifi` | `start` — «связь пропала», музыка без ударных; `end` — «связь вернулась», тарелка на следующей доле |
| `kts:event` `cakeMissed` | сдувшаяся дудка |
| `kts:event` `birthday` и сам `start` в окне `calendar.ktsBirthday` | с титульного экрана — дудка и фанфары с хлопушками (9 ноября длиннее и с залпом), на рестарте — только дудка. Один раз за забег |
| `kts:secret` | фирменный джингл «найдено»; `kotzilla` — сначала рык и мяу Котзиллы, `inevitable` — «дун-дун-ДУУУН» и весёлое «та-дам», `goodButton` — включает мажор, если пикапа не было |
| `kts:duck` | писк (если пикапа только что не было, например уточка в DOM) и короткий перезвон «в коллекцию» |
| `kts:ach`, `kts:skin` | фанфары ачивки и перезвон скина; если в том же кадре пришли `achievement`/`skinUnlock`, звучит один раз |
| `die` с `isRecord` | барабанная дробь 0,9 с, потом рекордный джингл (Ж22 «ЛЕГЕН… ДАРНО») |

Новые имена в `G.sfx`: `cake, cakeMissed, squeak, squeakFire, duckFound, frog, nom, vacuum, vacuumDown, voiceMsg, voicePop, vpn, jam, timesheet, clue, kazan, goodButton, meow, vivi, kotzilla, bot, secret, inevitable, birthday, wifi, salute`.

## Просьбы

**П1.**
1. `vpn` по контракту: для связи в слушателе `hit` ставить `hit.cancel = true`, ядро само зовёт `G.smash`. Глушение звучит на этот `smash`. Если пропустишь связь сквозь кролика без `hit` (например, через `o.deco`), глушения не будет, напиши мне.
2. `kts:event {id: 'wifi', phase: 'start' | 'end'}` — обязательно оба. Если забег кончился раньше `end`, звук сам вернёт ударные на `die` и `start`.
3. `o.drift` у `vacuum` задаёт высоту гула; препятствие узнаю по `type === 'vacuum' | 'voice'`.

**П2.** В `kts:npc` для `predict` и `kind` клади `text` — по длине строится фраза робота. Виви, если её ведёшь ты, шли с `id: 'vivi', phase: 'enter'`.

**П5.** Тайминг для «ЛЕГЕН… ДАРНО»: дробь начинается через `G.cfg.overlayDelay + 0,05 с` после `die` (≈0,7 с) и длится 0,9 с, «ДАРНО» (джингл рекорда) — на ≈1,6 с после `die`. Если шлёшь `kts:event birthday`, дубля не будет.

**П6.** Легендарную уточку узнаю по `def.legendary` в данных уточек, по `p.legendary` на пикапе или по `legend` в `p.spot`/`id`. Кнопку «Сделать хорошо» лучше слать пикапом `goodButton` (каждый забег), а не только секреткой: секретка срабатывает один раз в жизни.

**П3.** Если на 9 мая будет салют, шли `kts:event {id: 'salute', phase: 'start'}` — звучат свист и хлопки. Без события звука нет.

## Проверка

`node --check js/audio.js`, полный `node test/smoke.js`, `node test/fairness.js` — зелёные. Отдельно прогнал все события из таблицы в фейковом WebAudio с ?date=2026-10-07, 2026-11-09 и ?kts=off: без исключений и `exponentialRamp` к нулю, во время `wifi` ни одного удара, мажорный перезвон только в окне 10 с, все узлы KTS-звуков после окончания отключены, с ?kts=off событийных KTS-звуков нет.
