# П8 — визуальные эффекты KTS

Файлы: `js/fx.js` и `js/look.js` (только общие примитивы, без KTS-строк), `js/kts/fx.js` (вся KTS-логика и данные эффектов в `G.kts.add('fx', …)`; любой эффект выключается `on: false` у записи).

## API (у потребителей — фича-детект)

Общие, есть всегда, в том числе при `?kts=off`:

- `G.fx.stamp(text, {x, alt, color, rot, life})` — штамп-печать: двойная рамка, затёртые чернила, удар с отскоком. Без `x/alt` — по центру кадра. Цвет по умолчанию красный, как «ОТМЕНЕНО» (`#d8342c`); для «— done» и «ГАСТРОКАЙФ» лучше зелёный KTS `#2fc46b` / `#2f8f5a`. Текст не переводится в капс. На экране до 3 штампов; тот же текст в первые 0,5 с не дублируется, другой штамп в пределах 0,3 с заменяет предыдущий. Сбрасываются на `start`.
- `G.fx.salute(x, alt, {colors, n, anchor})` — салют: искра взлетает и раскрывается шаром. Без координат — случайно в небе.
- `G.fx.sprite(canvas, x, alt, {w, vx, vy, g, drag, life, pop, rot, vr, sway, anchor, layer, a})` — частица-спрайт из общего пула (`layer`: `'back'|'front'|'screen'`).
- `G.fx.flame(x, alt, {n, vx, vy, size, life, spread, color, color2, anchor, layer})` — огонь из общего пула.
- `G.fx.confetti(n, palette)`, `G.fx.cannons(n, palette)`, `G.fx.palette('party', colors|null)`.
- `G.fx.flash(alpha, color) → bool` — единственный путь к вспышке: лимит WCAG (не больше 3 за секунду) и `G.calm` уже внутри. Свои полноэкранные вспышки не рисуйте.
- `G.look.tint(owner, color|null, a)` — цветные края кадра от модуля (плавно, кто поставил — тот снимает).

Только при включённом KTS:

- `G.fx.react(kind, x, alt, {n, size, anchor, layer})` — реакции канала, нарисованные процедурно и закэшированные: `fire` 🔥, `party` 🎉, `heart` ❤, `like` 👍, `green` 💚. Без координат — над головой кролика. Не больше 10 в секунду.
- `G.fx.ktsConfetti(n)` — зелёное конфетти с 💚 (при `G.calm` — 40%).
- `G.fx.ktsIcon(kind)` — закэшированный canvas иконки (`fire, party, heart, like, green, crown, squeak, glint`) для `drawImage`.

## Что П8 делает сам (не дублируйте)

| Событие | Эффект |
|---|---|
| `pickup` `cake` | `ktsConfetti(30)`, 🎉×2, зелёное кольцо |
| `pickup` `duck` | писк-бурст `(( ))` и жёлтые искры; уточки на экране поблёскивают |
| легендарная уточка на экране | огненный шлейф; при поимке 🔥×4, огненный бурст, мягкая вспышка |
| `pickup` `frog` (и `toad`) | три медленных зелёных кольца и «вдох-выдох» зелёных краёв кадра 4 с |
| `kts:secret` | вспышка через лимитер, 🔥×3, зелёное кольцо |
| `kts:event` `vivi` | корона и золотые искры над пылесосом |
| `kts:npc` `toxic` `blocked` | штамп «ЗАБЛОКИРОВАН» и искры |
| `kts:event` `wifi` `start`/`end` | глитч по краям кадра и холодные края; без `end` гаснет сам через 14 с и на `die` |
| `kts:event` `birthday` `start` | `ktsConfetti(22)` |
| `milestone` 13:00 и 18:00 в ноябре (`K.event('ktsBirthday')`) | `ktsConfetti(40)`, 🎉×3, два зелёных салюта |
| ЕБЛАН-РЕЖИМ (`G.flag('fever')`) | горит хвост кролика; при `G.calm` — статичный огонёк; на входе 🔥×2 |
| near-miss / рекорд в забеге / проигрыш с рекордом | 🔥 (75%) / 🎉×3 / 🎉×4 |
| морковка в ЕБЛАН-РЕЖИМЕ / любая морковка | ❤ (50%) / изредка 👍 (3%) |
| 9 мая, крыша, 19:30–20:00 | зелёный салют раз в 1,4–2,4 с |
| конфетти рекорда и вех | в KTS-режиме в палитре есть фирменный зелёный |

При `G.calm`: штамп без удара, реакции без пружины и покачивания, конфетти урезано, хвост статичный, вспышек нет, глитч без мерцания, салют без взлёта.

## Просьбы

- **П1.** Штампы — через `G.fx.stamp` с фича-детектом: «ЗАБЛОКИРОВАНО» на созвонах и пингах под VPN, «ВЕЧНАЯ ПАМЯТЬ» вместо «ОТМЕНЕНО» (в этот момент свой штамп в `pickups.js` не рисуйте), «ГАСТРОКАЙФ», «… — done». На торт своё конфетти не зовите. В `kts:event {id:'vivi', phase:'start'}` положите `x, alt` пылесоса (иначе беру ближайший `vacuum`). Если `kts:event wifi` закончился, шлите `phase:'end'`.
- **П2.** В `kts:npc {id:'toxic', phase:'blocked'}` передайте `x, alt` бота. Штамп сами не зовите — П8 ставит его на это событие.
- **П6.** У легендарной уточки поставьте `p.legendary = true` (или `legendary: true` у записи в `ducks` с `p.spot` = id записи). Для С06 «Друллеги» — `G.fx.ktsConfetti(…)`. Писк и блеск уточек П8 рисует сам.
- **П3.** Салют 9 мая на крыше П8 запускает сам по дате и локации `roof`. Если нужен ещё где-то — `G.fx.salute`.
- **Интегратор.** В контракт smoke можно добавить `G.fx.stamp` всегда и `G.fx.react` / `G.fx.ktsConfetti` при KTS. В CONTRACT стоит дописать общие `G.fx.salute/sprite/flame/flash` и `G.look.tint`.
