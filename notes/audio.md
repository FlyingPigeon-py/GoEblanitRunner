# audio — заметки для соседей

Сделано при интеграции: ядро шлёт `input` с source `control` на нажатия кнопок внутри сцены; «бзз» созвона звучит по `telegraph` с фазой `enter`; дождь за окном по `G.scene`.

Правки ядра не нужны. Всё ниже — необязательные просьбы: без них звук работает на фолбэках.

## API `G.audio`

- `muted`, `music`, `toggle()`, `setMuted(b)`, `setMusic(b)`, `unlock()`, `context()` — как в контракте.
- `volume = { music, sfx }` (0..1) и `setVolume('music' | 'sfx', v)` — громкость групп, хранится в `eblan.audio.vol`.
- `isReady()` — контекст создан и разблокирован жестом.
- `tone(f0, f1, dur, type, vol, delay)` — старый хелпер оставлен для совместимости.
- Хранилище: `eblan.muted`, `eblan.audio.music` (по умолчанию музыка включена), `eblan.audio.vol`.
- Клавиши (через событие `key`): `M` — звук целиком, `N` — только музыка. События `mute (bool)` и `music (bool)`.

## Просьбы

**ui.**
1. Кнопка «музыка» рядом с `#mute`: `G.audio.setMusic(!G.audio.music)`, иконку обновлять по событию `music`. В подсказке можно добавить «`N` — музыка».
2. По желанию — два ползунка громкости (`G.audio.volume`, `G.audio.setVolume`). Пометь их `data-noinput`.

**core (не обязательно).** Клики по `#startBtn`, `#againBtn`, `#mute` и по `#metaPanel` не шлют `input`. audio сам слушает `pointerdown/keydown/touchend/click` на `window` в фазе capture, так что звук разблокируется и без правки. Но если ядро или ui начнут слать `input` и на эти клики, будет чище.

**pickups.** Учёл твои заметки: `powerupEnd.reason === 'used'` — «чпок» пузыря, `'timeout'` — тихий спад, `'instant' | 'die' | 'start'` — без звука. `gold` звучит отдельно, у пауэр-апов звук идёт по `powerup` (свой у каждого id: `coffee`, `sick`, `magnet`, `feather`, `cancel`, `friday`). Пока активна `friday`, музыка переходит на «четыре в пол» (смотрю `G.powerups.isActive('friday')`).

**obstacles.** Использую твои события: `telegraph (o, def, 'enter' | 'lock')` — короткий звуковой сигнал по типу (ping — «плинь», laptop — «буп», deadline — низкое «дун», minute — «эм?», lock — щелчок); `clockRing (o)` — тихий короткий звонок будильника справа. Смерть по типу: clock, call, tasks, ping, laptop, deadline, minute — у каждого свой звук, неизвестные типы — общий «бдыщ». Новые типы звучат по подстроке в id, а явно звук задаётся полем `def.sound = 'clock' | 'call' | 'tasks' | 'ping' | 'laptop' | 'deadline' | 'minute' | 'other'`.

**meta.** `achievement` — фанфары, `skinUnlock` — короткий перезвон. Если ачивки приходят на экране проигрыша, они встают в очередь после грустного джингла.

**balance.** `combo {count}` — тихий тон растёт с `count` (count < 2 игнорирую).

## Как устроено

- Шина: `master → мягкий компрессор → лимитер → выход`. Группы `music` и `sfx` идут в `master`; джинглы проигрыша — в отдельную подшину, её глушу на рестарте.
- Музыка — лоу-фай в фа мажоре: секции intro/A/B/C/break, четыре гармонии, паттерны мелодии с вариациями. Мотив «да-вай еб-ла-нить» (C–F–D–G–F) открывает первую секцию и звучит на стартовом экране музыкальной шкатулкой под «тик-так».
- Темп 84 → 114 bpm от `G.state.speed` (кофе ускоряет и музыку). Ночью (вне 07–21) темп ×0.86, фильтр мягче, шкатулка вместо лида, пэды вместо стабов. Пауза — глухо и тише. Смерть — «остановка плёнки» (питч вниз), грустный джингл (или победный при рекорде), потом тихие часы раз в секунду.
- Планировщик: `setInterval` 30 мс, упреждение 0.18 с по `ac.currentTime`. На скрытой вкладке и при mute контекст усыпляется (`suspend`).
- Беззвучный режим iOS уважаю намеренно: `navigator.audioSession` не трогаю, чтобы не глушить музыку игрока из других приложений.
