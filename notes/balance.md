# balance — что есть и что нужно от других

Сделано при интеграции: `o.hMax` у `ping`, `steady` у `call`, плавный разгон кофе и «Пятницы» (1.5 с), звук созвона по `telegraph`.

Правки ядра не нужны. Всё ниже работает и без просьб, просьбы только улучшают результат.

## Как устроен режиссёр

- Дорожка в мировых единицах пройденного пути: у каждого события есть `D` — момент, когда центр препятствия доезжает до хитбокса кролика. Спавн «точно в срок», за правым краем; `o.x` после `make` переставляется так, чтобы прибытие совпало с `D` с учётом `o.drift`. Обработчики `spawn` видят предварительный `x`: он тоже за экраном.
- Форма препятствия меряется точечными пробами самого `def.hit` (сетка 8 ед. + бисекция, ~0.1 мс на спавн). Классы: `jump` (перепрыгнуть), `duck` (пробежать снизу), `free` (одиночным прыжком не достать), `solo` (летающее с `update`, кроме `call`: высота непредсказуема, вокруг него двойной запас).
- Интервалы считаются из `G.cfg` (время в воздухе `T = 2·jumpV/gravity`, время подъёма до высоты h, полуокно `(w/2 + r)/(v·drift)`), формулы — в `minGap`. Проверено ботами-планировщиками по точной физике ядра: «поздний», «ранний», «средний» и «человек» (±73 мс шума). 4 экрана × 420 с на каждый стиль — 0 смертей.
- Волны: напряжение 10–18 с → передышка с дугой морковок по траектории прыжка (иногда двойного) → новая волна. Первые ~10 с — обучение по сценарию. Новый тип показывается отдельно, с запасом («дебют»).
- `G.speedAt` переопределён: старт с 0.9×, к 10 с выходит на кривую ядра, после 240 с растёт ещё на 7% от `speedGain`, на узком экране (W ≈ 520) прирост на 10% меньше.
- `G.cfg.jumpBuffer` 0.12 → 0.15.

## Очки

- Near-miss: `G.addBonus(5, { label: 'ЕЛЕ-ЕЛЕ! +5 мин', kind: 'near', x, alt })`.
- Комбо: +1 за любой подбор, near-miss и сбитое во время «Пятницы». Множитель `G.setMod('score', 'combo', …)`: ×1.5 с 5, ×2 с 15, ×2.5 с 30, ×3 с 50.
- Сброс: пропустил морковку (она ушла за кролика), удар без неуязвимости, в том числе лопнувший «Больничный», смерть. Морковки дождя в 13:00 не считаются.
- Событие `combo { count, mult, reason, lost }`. При сбросе `count: 0, mult: 1`, `reason`: `'miss' | 'hit' | 'shield'`, `lost` — сколько было.
- При сбросе с `lost ≥ 3` (кроме смерти) balance сам показывает `G.fx.popup('КОМБО СГОРЕЛО')`.
- Во время «Пятницы» за каждое сбитое: `G.addBonus(3, { kind: 'smash' })`.

## Вехи (`G.milestones`, 15 штук) и события

| Время | Событие |
|---|---|
| 09:30 | линия морковок прямо под тост |
| 10:00 | «стендап»: три созвона подряд, под ними надо пробежать |
| 11:56 | мем-будильник (`r: 26, hands: 'meme'`) доезжает до кролика ровно в 11:56; над ним дуга с золотой морковкой |
| 13:00 | 5 с без препятствий, с неба падают морковки |
| 14:00 | скорость ×0.86 на 8 с |
| 15:00 | 14 с только классика: будильник, таски, созвон |
| 16:00 | коридор + связка созвонов |
| 17:59 | время ×0.3, пока часы не дойдут до 18:00 |
| 18:00 | скорость ×1.12 на 15 с, морковок больше |
| 20:00 | передышка-«серия» |
| 22:00–06:00 | больше созвонов и воздушных паттернов |
| 00:00 | передышка с дугами двойного прыжка |
| 03:00 | сразу пик волны |
| 06:00 | +60 мин (`kind: 'milestone'`) |
| 09:00 следующего дня | +120 мин |

Скоростные окна разгоняются и тормозят плавно, за 2 с.

## Просьбы

**obstacles**
- Параметры `make`, на которые опирается balance, — сохраните: `clock {r, hands}`, `tasks {n}`, `call {level: 0 | 1 | 2}` (0 — перепрыгнуть, 1 — пробежать снизу, 2 — высоко).
- У анимированных наземных типов, у которых форма меняется со временем (`ping` прыгает до ~71), проба при спавне видит только текущую фазу. Если выставить `o.hMax` (или `def.height`) — максимальную высоту опасной зоны, — balance возьмёт её. Сейчас честность держится на основном запасе `T + m`, но дуги и «лесенки» могут считаться по заниженной высоте.
- Летающие с `update`, кроме `call`, balance считает непредсказуемыми (`solo`). Если тип летает на фиксированной высоте, а `update` нужен только для анимации, пометьте `def.steady = true`: balance это уже читает и будет ставить такой тип в обычные связки.

**pickups**
- «Третий кофе» (скорость ×1.15) и «Пятница» (×1.25) меняют скорость мгновенно. Если разгон длиннее ~1 с, кролик в долгом двойном прыжке приземляется не туда, куда целился. Боты умирали только на этом. Плавный разгон за 0.5–1 с (как у моих окон) убрал бы это.
- Морковки дуг, линий и после приземлений balance спавнит явно `'carrot'`. Пикапы `null` — примерно раз в 3–4 с, на вершине прыжка над препятствием или под созвоном.
- Морковки дождя помечены `p.balRain`. Пока падают, balance двигает `p.alt` (`p.balFall`, `p.balVy`) и отпускает их, как только магнит ставит `p.pulled`.

**fx / ui**
- `combo` теперь с `reason`/`lost`. Если fx захочет сам показывать «сгорело», скажите — уберу свою всплывашку.
- Вех стало 15, тосты в первые минуты идут примерно раз в 15–30 с.

**audio**
- `call` спавнится за 0.1–0.6 с до появления в кадре. Для звука «появился» точнее `telegraph` с фазой `'enter'`.

**meta**
- Мем-будильник гарантированно приезжает в 11:56, так что ачивку «умер в 11:56» теперь можно взять намеренно.
- Идеи ачивок: комбо ×3, «пережил морковный дождь», дотянул до 09:00 следующего дня (`min` 1440).
