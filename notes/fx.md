# fx — заметки для соседей

Сделано при интеграции: `drawDizzy` пропускается при `G.bunnyDizzy`, звёзды ачивки — у тостов справа, `G.calm` вместо своего matchMedia.

Правки ядра не нужны. Всё ниже — необязательные хуки: без них fx работает на фолбэках.

## API `G.fx` (старые сигнатуры сохранены)

- `burst(x, alt, {n, speed, color, life, size, gravity, vx, vy})` — круглые искорки, как раньше.
- `popup(x, alt, text, {color, size, life, fill, rot})` — мем-стиль: белая заливка, тёмная обводка, цветная «тень». `color` теперь цвет тени (так любой цвет читается в обеих темах), `fill` — заливка, если очень нужно. Текст переводится в верхний регистр. Одновременно живут максимум 10 всплывашек, пересекающиеся раздвигаются по вертикали.
- `shake(n)` — n в «пикселях», как раньше (14 ≈ смерть). Внутри — плавная тряска на шуме с затуханием.
- `dust(x, n)`, `sparks(x, alt, {n, speed, color, color2})`, `stars(x, alt, n, {speed, size})`, `ring(x, alt, {from, r, width, life, color, squash, back})`, `confetti(n)`, `feathers(x, alt, n)`, `paper(x, alt, n)`.
- `flash(alpha, color)`, `zoom(amount)` — с учётом prefers-reduced-motion (там они ничего не делают).
- `hitstop(scale, sec)`, `slowmo(scale, sec)` — модификатор `time` с владельцами `fx-hitstop` / `fx-slowmo`, снимается таймером и на `start`.
- `reduced` (prefers-reduced-motion), `count` (живые частицы, предел 400).

`G.camera` целиком ведёт fx (x, y, rot — тряска; zoom, fx, fy — зум-удар с фокусом на кролике). Другим модулям его не писать.

## Просьбы

**balance — near-miss.** Начисляй через `G.addBonus(n, { kind: 'near', x, alt })`. fx на `pass` с `near` сам рисует полосу «ЕЛЕ-ЕЛЕ!» и делает слоу-мо, поэтому для `kind`, содержащего `near`, всплывашка показывает только «+N мин», а `label` игнорирует, чтобы слово не дублировалось.

**balance — комбо.** `combo {count, mult}`: fx показывает «КОМБО ×count» начиная с count ≥ 2, держит одну всплывашку и перезапускает её с пружиной, размер и цвет растут с count; на каждом 5-м — кольцо и зум. count < 2 (сброс) игнорируется.

**obstacles — новые типы.** Для обломков при `smash`/`die` можно задать в определении `fx: { debris: 'paper' | 'shards' | 'feathers', colors: ['#…', …] }`. Без этого: `tasks` — листки, `call` — перья и осколки карточки, `clock` — осколки корпуса, прочие — по `kind` (`air` — перья, `ground` — осколки). Центр берётся из `o.fly`, иначе `o.h`, `o.r`, `o.n`.

**pickups.** `def.color` (строка) уже используется для искр/кольца при подборе и для кольца `powerup`. На `powerupEnd` с `reason: 'instant'` fx кольцо не рисует.

## Слои fx

- `BACK + 1` — скоростные линии (за сущностями).
- `BACK + 2` — полоса «ЕЛЕ-ЕЛЕ» (за кроликом и препятствиями, чтобы не закрывать их).
- `BUNNY - 1` — пыль и кольца прыжка за кроликом.
- `FX` — искры, осколки, звёзды, перья, звёздочки над головой после смерти.
- `FRONT + 5` — всплывашки (поверх переднего плана сцены).
- `SCREEN` — виньетка, конфетти рекорда и вех, вспышка.
