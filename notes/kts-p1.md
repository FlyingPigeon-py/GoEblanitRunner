## API, которое добавлено (без KTS-строк, работает и при `?kts=off`)

- `G.director.ban(types, untilT, fromT?)` — не ставить типы с прибытием в `[fromT, untilT]` (запас 1.5 с на сдвиг интервалом); `G.director.banned(id, t)`. Запреты живут один забег.
- `G.director.queuePickup(id, {fromT, toT, double?})` → `{placed, dropped}` — пикап в вершине одиночной дуги морковок, между паттернами, вне `busy`-окон и all-hands. Окно по прибытию; не успел — `dropped`. Живёт один забег.
- `def.chaseBan` у препятствия — не ставить во время погони (как пинг).
- Препятствия: `o.ghost` (полупрозрачное, без телеграфа), `o.stamp` (надпись-штамп поверх), `o.face = {draw(ctx, x, y, w, h, t, o)}` — свой экран у созвона, `def.floorOf(o)` — где лежит сплющенный, `def.stompWord` — слово для «Отложить».
- `G.obstacleKit` — `tickWarn, warnChip, squashed, ghosted, circleRect, bubblePath, glow, weightFor, shadow(id, fn), motion(), calm()`.
- `G.powerups.register(def)` — пауэр-ап с плашкой и индикатором; `G.powerups.stamp(text)` — большой штамп как у «Созвон отменили».
- Пикап: `def.shadowW` — ширина тени.
- `G.ktsItems` (только при KTS) — помощники П1: `item, say, toast, popup, tOf, sprite, blit, event`.

## Просьбы

**Интегратор**
- В `test/smoke.js` `TOAST_KINDS` нет `kts`, поэтому тосты П1 пока с видом `info` (константа `TOAST_KIND` в `js/kts/obstacles.js`). Когда smoke пустит `kts`, поменять одну строку.
- В CONTRACT: API из раздела выше, события `kts:event` `cakeMissed {text}`, `timesheetMissed`, `wifi {until}`.
- `test/fairness.js` теперь грузит `js/kts/kts.js`, `js/kts/data/{people,calendar,items}.js` и `js/kts/obstacles.js`.

**П2 (modes.js, NPC)**
- В `STOMP_WORD` брать `def.stompWord`, если есть: у пылесоса «ВЫКЛЮЧИЛ», у голосового «СТОП-СЛОВО». Сейчас там «ОТЛОЖИЛ».
- Нужны `G.modes.addMeter(delta, reason)` и `G.modes.pushChase(delta)`: жабонька даёт +25 к Ебланометру и +60 к отрыву тимлида. Пока зову `_fill(25)`, отрыв без API не трогаю.
- На `kts:event {id:'timesheetMissed'}` — тимлид в 19:30 стартует ближе (отрыв 110 вместо 140).
- Виви считает KTS-NPC на экране по `kts:npc` (любая фаза — на экране, `leave` — ушёл) и не прыгает, пока там бот. Боту — не входить между `kts:event vivi start` и `end`.

**П4 (прогресс)**
- Счётчики: `denis` (торты), `vivi` (стартует с 2 при первом событии; до него `counter` = 0 — показывать `max(2, counter)`), `frogs`.
- `echpochmak` и `chakchak` с флагом `def.carrotLike` — для целей «морковки» в `meta.js` считать их морковками (сейчас `isCarrot` смотрит только `carrot`/`gold`). `G.state.stats.carrots` они увеличивают сами.

**П5 (экраны)**
- `kts:event cakeMissed` несёт готовый `text` (из `items.cake.missed`, с фолбэком без Дениса) — строка для экрана проигрыша.
- Значок Wi-Fi в HUD — по `kts:event wifi` `start`/`end`.

**П6 (секретки)**
- П1 открывает `stopword` (прыжок на голосовое или «стоп»/«cnjg» в забеге, пока голосовое на экране), `wednesday` (жабонька), `vivi` (счёт ≥ 10). Свой обработчик «стоп» не нужен; повторный вызов `K.secret` безвреден.

**П7 (звук)**
- Пикапы: `cake` (дудка), `frog` (ква), `timesheet`, `echpochmak` (уже `def.golden` — играет «золото»), `chakchak` (лучше звук морковки), `khryuchevo`; пауэр-ап `vpn`.
- Препятствия: `voice` (`def.sound = 'ping'`, можно бубнёж), `vacuum` (`'other'`, короткий гул). `kts:event wifi` — музыка без ударных, `vivi start` — мяу.

**П8 (эффекты)**
- Торт зовёт `G.fx.ktsConfetti(n)`, если есть, иначе `G.fx.confetti(n)`. Штампы П1 рисует сам.

**П3 (локации)**
- Пылесос смотрит на `G.scene.loc.id` (`living`, `kitchen`, `office`, `bedroom`). Вай-фай — `kts:event wifi`.
