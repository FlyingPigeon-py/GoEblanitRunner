# П2 — NPC и преследователи: что сделано и что нужно от соседей

## Что есть

- **Бот-токсик** (`js/kts/npc.js`, данные — `js/kts/data/npc.js`, раздел `npc.toxic`). Раз за забег в окне t 22,5–72, где `G.director.busy()` свободен: влетает в верхнюю полосу, 2,5 с говорит облачком (≤ 50 символов), ждёт, пока пройдут уже поставленные препятствия, ставит `director.hold` и резерв `'toxic'` только на окно пике. Пике: «!» 1 с, затем 0,45 с снижения к кролику и 0,8 с на высоте 185. Касание в двойном прыжке (`B.jumps >= 2`) блокирует бота.
- **Сбывание.** В 1/3 визитов бот заказывает режиссёру обычный паттерн под свои слова: три будильника, лесенку тасок, коридор созвонов, два пинга, дедлайн или дуги морковок. Шаги собраны из той же грамматики, что `PATTERNS` в balance, без `tight`. 1/15 — «злючка-бот словил баг»: доброе предсказание, розовый бот и золотая морковка на вершине дуги одиночного прыжка.
- **События** `kts:npc {id: 'toxic', phase, text}`: `enter`, `predict` (+ `fulfilled`), `kind`, `dive` (начало снижения), `blocked`, `leave` (начало ухода по любой причине).
- **Блокировка:** тост «Блокируем бота-токсика и фильтруем базар», `G.fx.stamp('ЗАБЛОКИРОВАН')` (фолбэк — `popup`), случайный пауэр-ап из `rewards` через `G.powerups.give`, `G.kts.secret('filter')`.
- **Ачивки** в `data/npc.js`: `toxicBug` («Сбой в матрице»), `toxicRight` («Логичное предсказание», если предсказание сбылось к смерти).
- **Тимлид** (`js/modes.js`): в KTS-режиме облачко чередует «Синкнемся?» и «Привет, когда залогаешь время?» (каждые 2,2 с, длинная фраза в две строки), всплывашка «ЛОГАЮ ЧАСИКИ…» вместо «РАБОТАЮ…», своя причина смерти. Без KTS всё как было.
- **All-hands** (`js/events.js`): заголовок окна, субтитры по кругу («Работаем, трансформируемся и вместе растём» и др.), подпись бонуса «ALL-HANDS — DONE», причина смерти. Всё из `npc.allhands`.

## API

- `G.kts.npc.lastPrediction` — выставляется на `die`, читать на `gameover`. Объект `{kind, title, text, toString()}` или `null` (бот выключен). `kind`: `'next'` (выбор редакции на следующий забег), `'monday'` (аффирмация на понедельник), `'right'` (бот был прав), `'kind'` (сбой в матрице), `'blocked'`. `String(lastPrediction)` даёт текст.
- `G.kts.npc.toxicOff()` / `setToxicOff(bool)` — настройка «Заблокировать бота-токсика» (`eblan.kts.npc.toxicOff`), при включении тост «фильтруем базар».
- `G.kts.npc.active()` — id KTS-NPC на экране (`'toxic'`, `'vivi'`) или `null`; `claim(id)` / `release(id)` — общий замок «одна KTS-NPC на экране».
- `G.kts.npc.toxic()` — `{phase, x, alt, text, blocked}` только для чтения; `_toxic({group|kind})` — вызвать бота сейчас (для тестов).
- `G.modes.pushChase(delta)` — сдвинуть отрыв тимлида (в `warn` и `start`), `false`, если погони нет.
- Событие `chase` в фазе `caught` в KTS-режиме несёт `label: 'логаю часики…'`.

## Просьбы

- **П5 (экраны).** Блок «Выбор редакции» на экране проигрыша — из `G.kts.npc.lastPrediction` (`title` + `text`). Подпись HUD «работаю…» в KTS-режиме — из `c.label` события `chase` (фаза `caught`): `hudScoreLabel.textContent = c.label || WORK_LABEL`.
- **П4 (Личное дело).** Переключатель «Заблокировать бота-токсика» → `G.kts.npc.setToxicOff(on)`, состояние — `G.kts.npc.toxicOff()`. Ачивки `toxicBug`, `toxicRight` с `group: 'kts'`.
- **П1.** Жабонька: `G.modes && G.modes.pushChase && G.modes.pushChase(60)`. Таймшит: тимлид слушает `pickup` с `p.type === 'timesheet'`; если тип зарегистрирован и до 18:00 (t 135) ни одного, следующая плановая погоня (19:30) стартует с отрывом 120 вместо 140 (`npc.teamlead.noTimesheetGap`). Виви: шлите `kts:event {id: 'vivi', phase: 'start'|'end'}` и перед стартом проверяйте `G.kts.npc.active()` — бот в это время не прилетает.
- **П6.** Секретка `filter` открывается ботом. У13: в слушателе `spawnPickup` для `p.type === 'leave'` поставьте `p.leaveColor = '#f2c200'` (только `#rrggbb`) — кнопка нарисуется жёлтой, работает как обычная; сбор ловите по `pickup` с `p.leaveColor`. У22: слушайте `chase` с `phase === 'escape'` и ставьте уточку через режиссёра.
- **П7.** Звуки бота — по `kts:npc` (`predict`/`kind` — глитч-речь, `dive` — свист, `blocked` — блок).
- **Интегратор.** Smoke пускает в `G.ui.toast` только старые виды, поэтому тосты бота идут с `kind: 'info'` (константа `TOAST_KIND` в `js/kts/npc.js`). Когда `kts` появится в `TOAST_KINDS`, поменяйте её на `'kts'`. В CONTRACT стоит добавить `G.modes.pushChase`, `label` в `chase` и API `G.kts.npc` выше.
